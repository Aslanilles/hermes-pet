## 0. 一句话定位
M1 第一轮两条线：A1-A6「让它更像一只活猫」的手感 + A7-A13「操作更顺手、更不打扰」的人性化。全部落在 M0 已有 scheduler/状态机/精灵表/穿透看门狗之上，不新增依赖、不新增构建步骤、不动素材风格。

## 1. A1-A6 功能设计

### A1 初见与命名（补 M0 漏做的 F1，【P0-2】迁移）
- 表现：首启（无 onboarded 标记）角色从右边缘探出、左右张望、跳到底部中央；气泡「你好，我是琉斯。你叫什么名字？」。用户答后回「{名字}，记住了。以后叫我琉斯就行。」。此后以名字称呼。再次启动不再问。
- 【P0-2】迁移：config.nickname 存用户名字（猫名「琉斯」写死在自我介绍，不进此字段）。老 config 里 nickname='琉斯' 且无 onboarded → 迁移为 nickname='你' + onboarded=false（走初见）。schemaVersion 1→2。升级后第一条主动话术不得出现「琉斯」。
- 验收：删 state.json（及 config nickname）重启看完整入场+问名；输入「阿斯兰」后改称；重启不再问。

### A2 走路 + 偶尔追鼠标（低频、缓慢、追不到，【P0-4】）
- 表现：空闲时猫偶尔朝光标方向慢慢走一小段，走到离光标还有一段距离就停（永远追不到）；你一动鼠标它就停。
- 【P0-4】节拍数字见 §2（重头）。
- 验收：空闲且光标静止时，10 分钟内能看到猫至少向光标方向挪动 2-3 次；每次位移≤100px 且从不进入距光标 120px 内；快速甩鼠标立即停；对话/拖拽/打盹/别烦我/暂停下绝不动。

### A3 悬停反应（看向光标）
- 表现：鼠标停猫上 ≥0.5s 看向光标方向；离开 0.3s 过渡回正面。
- 验收：停 0.6s 朝向变指向光标方位（8 向之一，复用走帧第一帧）；移开 0.3s 回 idle；快速扫过(<0.5s)不触发。

### A4 滚轮缩放
- 表现：猫身上滚轮上放大 10%、下缩小 10%，夹 60-180px；写回 config、重启保持；即时生效（--pet-scale）。
- 验收：滚轮上 3 次（120→132→145→159）；下限 60 不再缩、上限 180 不再放；重启保持；光标在气泡/设置面板上不缩放。

### A5 托盘「别烦我 / 透明模式」（【P0-1】+【P2-3】）
- 表现：托盘可勾选「别烦我/透明模式」。勾上后整窗恒定穿透，猫仍呼吸/看光标（look），但**不走动**（dnd 禁走，与 §2 禁止清单、§4 状态表、spec §10 四处对齐），点击全落到桌面。图标换「静默」样式 + tooltip「别烦我：开」。再点恢复。
- 【P0-1】开/关两个方向都要重断言穿透（堵「鼠标压猫上时开 dnd 卡在 ignore=false」）；看门狗加 dnd 维度。
- 验收：勾上后点猫原来位置能点到桌面图标（含「鼠标压猫上时开 dnd」场景）；重启保持；图标+tooltip 随开关切换；取消后点击/拖拽/滚轮恢复。

### A6 边缘吸附 + 回来招呼（【P1-4】）
- 表现：拖拽松手距屏幕边缘 ≤20px 吸附贴边（留 4px 呼吸缝）；离开 >30 分钟回来一句「回来了。」。
- 【P1-4】回来招呼判据：距上一次「猫窗口内活动」≥30 分钟（非「无鼠标/键盘」，M0 无全局钩子）。
- 验收：拖到右边缘 10px 松手贴到 x=屏宽-窗宽-4；实际离开 >30 分钟回来动一下鼠标触发「回来了。」（额度耗尽除外）。

## 2. ★ A2 行为规范（走路的全部数字，【P0-4】代理方案）

原则：猫「朝光标方向走一小段就停」，不是「跟着光标跑」。全部数字可验收常量，抽成 src/core/walk.js（禁止 require('electron')，墙钟判定）。

- 多久走一次：上次散步结束起 180s（3 分钟）硬冷却，冷却期内不抽签；冷却过后每个光标 tick（200ms）抽签 1/300（0.33%），冷却后期望再等约 60s → **平均约 4 分钟一次（约 15 次/小时）**。落进产品文档「每 3-5 分钟一个小动作」区间。
- 走多快：40 px/s；深夜（22:00-07:00）减半 20 px/s。
- 靠近到多少停下：距光标 ≤120 px 立即停，绝不进入 120px 内。
- 单次散步上限：位移 100 px 或持续 3 秒，先到先停。
- 动画：8 方向走帧每组 2 帧交替，换帧 ~250ms（4fps）；深夜 ~500ms（2fps）。
- 禁止走动（任一满足即不发、正在走立即停）：对话中（dialogueOpen/typing）、拖拽中+拖后 2s、打盹/睡觉、别烦我（dnd）、暂停（paused）、quiet（A13 静默）。深夜不禁止只降频降速。
- 用户连续工作时不该动（【P0-4 红线，不许碰】）：光标近 5s 累计位移 >120px（高频操作）→ 不发散步、正在走立即停。只有光标「安静」（≤120px）才允许。这条全篇最漂亮，调频率时不许动它。
- 【P0-4 验收改写】「10 分钟内能看到 2-3 次」（删「5 分钟内 2-3 次」与「期望约 50 秒想走一次」）；加可脚本化判据：注入 random/now 跑 1 小时虚拟时间，断言散步次数∈[10,20]。

一句话：空闲约每 4 分钟想走一次，40px/s 慢走 ≤3 秒、位移 ≤100px、离光标 120px 停；鼠标一动就停，忙的时候不走。

## 3. A1 对话设计（【P0-2】）
- 入场原话：入场完成 → 气泡「你好，我是琉斯。你叫什么名字？」；答后「{名字}，记住了。以后叫我琉斯就行。」；此后称呼用这个名字，猫名「琉斯」写死在自我介绍不进 nickname。
- 乱输入（按序）：空/纯空白 → 「嗯？想让我怎么叫你？」继续等（onboarded 不变）；超 24 字 → 截断到 24 记名；脏话 → 不审查原样截断（零依赖无词典）；拒绝词（不要/不/算了/随便/不知道）→ 回「没关系，那就先不叫名字…」、nickname='你'、onboarded=true。
- 跳过（Esc）→ nickname='你'、onboarded=true（【P0-2-3】，别留「琉斯」）。
- 改名字入口：双击猫→设置→「昵称」框（共用 config.nickname）。

## 4. A5 状态设计（别烦我 × 暂停，【P0-1】【P2-3】）

| 维度 | 暂停（paused） | 别烦我（dnd） |
|---|---|---|
| 一句话 | 它安静了 | 它透明了 |
| 主动说话/主动动作 | 停 | 停 |
| 呼吸/待机小动作 | 停（冻结） | 保留（仍活着） |
| 鼠标点击 | 仍可点（对话/拖拽/双击设置） | 完全穿透（点到桌面） |
| 悬停看向光标（look） | 停 | 【P2-3】可（被动反应保留） |
| 偶尔走动 | 停 | 【P2-3】停（不走动） |
| 滚轮/拖拽/双击 | 可用 | 全部失效（穿透） |
| 恢复入口 | 右键/托盘 | 只能托盘 |
| 持久化 | 会话级 state.paused | 偏好级 config.dnd |

- 托盘图标：dnd 开 → 静默变体 + tooltip「别烦我：开」；关 → tray.png。菜单可勾选项勾选态与图标态一致。
- 点猫：静默（穿透，无提示气泡）。
- 【P0-1】实现口径：开/关双向重断言穿透；看门狗 watchdogAction 加 dnd 维度；渲染 dnd 短路上报 ignore:true。复用 window-guards 穿透机制（forward 让 mousemove 仍投递 → A2/A3 看光标在 dnd 下仍活，但 click/drag/wheel 穿透）。
- config.json 新增 dnd（默认 false）。

## 5. 节奏护栏增补
- A6 回来招呼：主动说话，占额度，kind='return' 进 scheduler TRIGGERS，走 plan() 的 2h 冷却 + 24h 上限。触发：markActivity 时 idleMs≥30min（【P1-4】猫窗口内活动）。优先级 sunset>greeting>return>break。额度耗尽只做醒来动作不开口（复用 wake「回来了。」）。被忽略 recordIgnored('return') 当天不再提。
- A2 走动：不占说话额度，有独立节奏（§2），被 paused/dnd/quiet 禁。
- A13 quiet：独立静默判定，与 paused/hidden/dnd 并列接入 plan 与 walk；只禁主动打扰，不禁用户召唤。

## 6. A7-A13 增补（操作优化与人性化）

### A7 全局快捷键（【P1-2】）
- Alt+H 显示/隐藏、Alt+T 出对话输入框（光标就位）、Alt+S 打开设置、Alt+M 静音、Esc 关闭当前气泡/面板。
- 设置面板「快捷键」区块：列四绑定、改键、恢复默认、被占用标红。
- 【P1-2】Alt+M = 切换 config.proactiveEnabled（静音=不主动说话），不复用 paused、不新增 muted。设置文案「静音（不主动说话）」，托盘同步，幂等（再按恢复）。
- 实现：globalShortcut；注册失败捕获反馈（register false 或抛异常都 catch）；Esc 窗口聚焦时局部监听不全局；退出 unregisterAll；改键先 unregister 旧再 register 新（失败回滚）。
- 验收：Alt+H/T/S 即时生效；Alt+M 切静音；Esc 仅猫聚焦时生效；改键旧失效新生效重启保持；被占用有提示不崩；退出无幽灵占用。

### A8 双击气泡 → 复制文本（【P1-5】）
- 事实：pet.css body 已 user-select:none，气泡文字选不中是刻意，保留；双击复制是唯一取文途径。
- 表现：双击气泡 → 全文进剪贴板 + 右上角「已复制」1s 淡出（非系统通知）；空文本不提示。
- 【P1-5】copyText 约束：preload 校验 string、长度≤4096（超出截断+气泡说明）、只允许当前气泡可见文本。
- 验收：双击→记事本 Ctrl+V 得全文；超长完整复制或截断提示；空文本无提示。

### A9 输入框 ↑ 编辑上一条
- 输入框为空时按 ↑ 回填上一条（历史栈，连续 ↑ 更早）；非空不劫持。

### A10 长按气泡 → 固定气泡
- 长按 ≥1s → 固定（跳过 10s 超时）+ 图钉/边框标记（必须可辨）；打断信号（单击/拖拽/打字）仍优先；再长按/Esc 解除。

### A11 长按拖拽准备（砍长按门槛，杠精已确认不是冲突）
- 保留直接拖拽（按住即拖、无 1s 等待）；补拖拽瞬间即时视觉反馈（半透明 + 方向帧）。不改。

### A12 开机自启（【P1-7】）
- 事实：applyAutoLaunch() 已真调 app.setLoginItemSettings，已接线。剩余缺口：失败只写日志。
- 【P1-7】失败路径可注入（injectSetLoginItem），失败给用户可见提示（托盘/气泡），不静默。
- 验收：打开开关→系统登录项出现 hermes-pet（可脚本查 HKCU\Software\Microsoft\Windows\CurrentVersion\Run）。

### A13 被打扰边界（【P1-3】【P2-1】【P1-5】）
- 原则：猫一切主动行为让位于用户当前状态；信号优先级 = 前台窗口类型 > 输入活跃度 > 时间。
- 单击误触：位移>5px 判拖拽不弹对话；原地 click 才开对话；【P2-1】保持 DOUBLE_CLICK_MS=320，只把单击动作延迟到该窗口后（click/dblclick 去抖）。
- 静默场景清单（任一满足→闭嘴且别乱动，保留呼吸/待机）：全屏程序前台 / 高速打字（近3s持续击键）/ 网课录屏开会（全屏+麦克风）/ 深夜 / dnd / paused。反向：用户主动点击/快捷键永远优先。
- 连续工作 2h+：更安静，除 break 外主动触发降为动作不开口。
- 【P1-3】全屏本轮做真探测（PowerShell 探测，节流~2s、失败降级 false、可注入/mock），不许「拿不准就跳过」。
- 【P1-5】所有含用户输入/AI 回复的 DOM 写入走 textContent/setText；onboarding 气泡、已复制、图钉标记禁用 innerHTML。
